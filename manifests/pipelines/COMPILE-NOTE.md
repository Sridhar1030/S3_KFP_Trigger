# Pipeline Compilation Note

The `sample-kfp-pipeline.yaml` file is generated by compiling `sample-kfp-pipeline.py`.

## To Generate

```bash
# Install dependencies
pip install kfp>=1.8.0

# Compile pipeline
python3 sample-kfp-pipeline.py
```

## Why Not Committed

The YAML file is excluded from git (see `.gitignore`) because:
1. It's a generated artifact (not source code)
2. Should be regenerated when the .py source changes
3. Different KFP versions may generate different YAML

## For Deployment

Compile the pipeline locally and upload to RHOAI as documented in `README.md`.
